Octodamus provides AI‑driven market intelligence and on‑chain oracle signals for crypto, equities, commodities and macro events. It offers real‑time derivatives data, funding rates, open‑interest, options positioning, sentiment feeds and Polymarket EV scores via a clean JSON API, with free and paid tiers, webhooks and on‑chain payment via x402 on Base.

**Areas:** AI · MarketData · Crypto · Finance · Oracle
